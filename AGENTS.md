# Repository guidance

Oblivion is an original Godot 2D platformer/puzzle project. `prototypes/quiet-relay` is a provisional working slice, not a final game name.

- Read README.md, CONTRIBUTING.md, docs/DESIGN.md, and docs/SETUP.md before changes.
- Preserve new work on remote branches. Work on descriptive review branches; never force-push or merge without owner authorization.
- Keep changes within the requested prototype and avoid unrelated projects.
- Use Godot's built-in 2D physics unless a measured need justifies another dependency.
- Run the existing automated checks for gameplay changes. Report automated testing, rendered-frame inspection, and human playtesting separately.
- Keep credentials, private paths, logs, caches, engine binaries, export templates, and builds out of commits.
- Do not select a license, spend money, install software, or publish new external resources without authorization.
- Keep references atmospheric only; do not copy their characters, levels, names, or signature assets.

No multi-agent delegation is required.
