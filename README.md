# Oblivion

An original 2D platformer/puzzle game in development with Godot. The design aims for a mysterious, lonely world, discovery, and occasional danger. Reference games inform atmosphere only; characters, levels, names, mechanics, and signature assets should be developed independently.

The working prototype is [The Quiet Relay](prototypes/quiet-relay/README.md), a small movement-and-puzzle slice with five hearts, drifting platforms, and a harmless evasive training dummy. Its name is provisional. Carry a warm weight to a cradle on the highest platform to restore the chamber, or chase the dummy and test one-damage baton swings with the left mouse button. The player runs at 255 px/s and the dummy at 247 px/s, giving a small pursuit advantage.

Start with [setup](docs/SETUP.md), [design and movement tuning](docs/DESIGN.md), [moving-platform/chase revision](docs/MOVING_CHASE_REVISION.md), and [collaboration guidance](CONTRIBUTING.md). The Godot project is `prototypes/quiet-relay/project.godot`.

Completed, tested updates are maintained on `prototype/quiet-relay-collaboration` in [draft PR #1](https://github.com/deadclass/Oblivion/pull/1). Review and owner approval precede merging. This describes the authorized workflow; individual update publication is verified and reported after its remote write succeeds.
