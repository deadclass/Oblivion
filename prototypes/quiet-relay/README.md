# Oblivion Movement Lab

Free practice on a flat floor with three one-way platforms and three inert, named knockback dummies. There is no objective or enemy progression. The previous verified sandbox remains preserved separately.

Current controls: A/Cross jumps; X/Square always uses the sword; B/Circle dodges; LB/L1 blocks; RB/R1 dashes; RT/R2 uses the selected ranged weapon; Y/Triangle cycles Bow, Boomerang, Bomb; LT/L2 cycles the highlighted target. Dash plus melee within 80ms produces a sword dash. Rising-spin recovery is left out of this revision.
